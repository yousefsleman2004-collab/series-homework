# Series Homework

פרויקט JavaScript לניהול סדרות, עונות ופרקים. בפרויקט השתמשנו בפונקציות לעבודה עם מערכים ואובייקטים, ולעדכון נתונים בלי לשנות את המקור.

## איך מריצים את הבדיקה?

פותחים את הטרמינל בתיקיית הפרויקט ומריצים:

```bash
node check.js
```

## שאלות

**1. בפונקציה `addEpisode` לא מספיק לכתוב `{ ...show }`. אילו אובייקטים ומערכים יצרתם מחדש, ולמה?**

יצרנו עותק חדש של האובייקט `show`, מערך חדש של `seasons`, עותק חדש של העונה שאליה מוסיפים את הפרק, ומערך חדש של `episodes`. עשינו זאת כדי להוסיף את הפרק בלי לשנות את הנתונים המקוריים.

**2. בתקלה #3 העמית כן עשה עותק עם `...`. למה זה לא עזר?**

הוא יצר עותק רק של האובייקט החיצוני `show`. המערכים והאובייקטים הפנימיים עדיין היו משותפים למקור. לכן, כשעשה `push`, הוא שינה גם את הנתונים המקוריים.
